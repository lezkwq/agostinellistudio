# Agostinelli Studio

Site institucional do Agostinelli Studio, salão de beleza em Camboriú, Santa Catarina.

## Desenvolvimento local

Requer Node.js e npm.

```sh
npm install
npm run dev
```

## Conteúdo do site

- Agendamentos pelo WhatsApp
- Serviços de cabelo, manicure, pedicure, sobrancelhas e cílios
- Portfólio de trabalhos e fotos do espaço
- Avaliações, endereço e contatos do studio
